# Gloam Code

**Gloam Code** — это десктоп AI-агент для разработки, собранный как форк
[opencode](https://github.com/anomalyco/opencode) (лицензия MIT) и оформленный
в собственном бренде **Gloam**, едином с Telegram-экосистемой Gloam.

> Это «моё приложение» на базе opencode: свой логотип, своя тема, свой дефолтный
> провайдер моделей и своя подписка. Апстрим остаётся источником обновлений.

---

## Что получает пользователь

- Готовые модели «из коробки» по подписке (например, `Claude Opus 4.8 (Gloam)`),
  без необходимости заводить свои API-ключи.
- Возможность добавить **свои** провайдеры — как в обычном opencode.
- Прозрачную автосмену ключей/провайдеров на стороне шлюза: если у одного
  ключа закончились токены, агент продолжает работу на другом **без уведомления
  и без обрыва диалога**.

## Архитектура

- Приложение видит **один** провайдер `gloam` и **один** базовый URL шлюза.
- Все реальные ключи и логика failover спрятаны в шлюзе (`gateway.gloam.ai`).
- Подписка = персональный токен с квотой, который шлюз выдаёт после оплаты
  (ЮKassa / Telegram Stars / CryptoBot) через Telegram-бота Gloam.

## Конфиг провайдера

Дефолтный провайдер описан в [`gloam.json`](./gloam.json). При сборке он
запекается в дистрибутив, чтобы пользователь после установки сразу видел модели
Gloam.

## Сборка и запуск (dev)

Репозиторий — монорепо на **Bun + Turbo**.

```bash
bun install
bun run dev           # запустить CLI/TUI локально
bun run dev:desktop   # десктоп-версия (beta)
bun run typecheck
```
